------------------------------------------------------------------------
The application is built using Angular 17+ with Standalone Components. 
Here is how the data and visual components flow together:

   +-------------------------------------------------------------+
   |                        index.html                           |
   |   (Root page containing the <app-root> tag and global CSS)  |
   +-------------------------------------------------------------+
                                  |
                                  v
   +-------------------------------------------------------------+
   |                      app.component.ts                       |
   |              (Loads AppComponent as the root)               |
   +-------------------------------------------------------------+
                                  |

   +-------------------------------------------------------------+
   |                      app.component.html                     |

3. EXPLANATION OF CODING DESIGN (FOR EASY UNDERSTANDING)
------------------------------------------------------------------------

* Standalone Components Imports:
  In Angular, standalone components do not use NgModule. Therefore, if a component template uses navigation links (`routerLink`), it MUST import `RouterModule` directly in its `@Component` imports array. We did this for both the Navbar and Home components.

* Why we use [routerLink] instead of href:
  Standard HTML `<a href="...">` reloads the entire browser window when clicked. Angular's `routerLink="..."` intercepts the click and loads only the necessary component inside the `<router-outlet>` dynamically. This creates a fast, single-page application (SPA) experience.

* Bootstrap + Custom Styles:
  We used Bootstrap for responsiveness (like grid systems `row`, `col-lg-6`, alignment `align-items-center`, and padding `py-5`). We then applied custom CSS (like gradients, border glows, and box-shadow transitions) to give the application a premium, custom-crafted aesthetic rather than a generic design.
